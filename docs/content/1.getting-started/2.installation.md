::steps
### Add the dependency

  :::code-group
  ```bash [pnpm]
  pnpm add -D unocss @outloud/css
  ```

  ```bash [npm]
  npm install -D unocss @outloud/css
  ```

  ```bash [yarn]
  yarn add -D unocss @outloud/css
  ```

  ```bash [bun]
  bun add -d unocss @outloud/css
  ```
  :::

### Use the preset

```ts [uno.config.ts]
import { defineConfig, transformerDirectives, type Preset } from 'unocss'
import { presetOutloud, type Theme } from '@outloud/css'

export default defineConfig<Theme>({
  presets: [presetOutloud({})],
  transformers: [transformerDirectives()],
})
```

### Import the reset styles

```css [styles.css]
@import '@outloud/css/reset.css';
```
::

## Numbers are px

A bare number in a class is px, written in rem with a 16px base: `p-16` is `padding: 1rem`, `gap-24` is `gap: 1.5rem` and `fs-14` is `font-size: 0.875rem`. It applies to every rule that would otherwise give a rem value, such as spacing, sizes, font size, line height and border radius.

Theme keys keep the Mini preset's values: `text-base` is 16px / 24px, `rounded-lg` 8px and `max-w-md` 448px.

## CSS layers

The preset sets no layers itself, and `reset.css` ships unlayered. To use layers, declare their order first and import the reset into one:

```css [layers.css]
@layer reset, vendor, app, uno;

@import '@outloud/css/reset.css' layer(reset);
```

Then put UnoCSS's preflights into `reset` and the utilities into `uno`:

```ts [uno.config.ts]
export default defineConfig<Theme>({
  presets: [presetOutloud()],
  outputToCssLayers: {
    cssLayerName: (layer) => (layer === 'preflights' ? 'reset' : 'uno'),
  },
})
```
